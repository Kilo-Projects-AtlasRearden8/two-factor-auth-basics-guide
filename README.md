# Two-Factor Authentication Basics

A plain-English beginner's guide to two-factor authentication (2FA): authenticator apps, SMS risks, recovery codes, and backing up your accounts. Step-by-step setup for email, banking, and AI tools, plus a printable worksheet.

## How to read it

**Read the docs:** Open any `.md` file in `docs/` in your preferred Markdown viewer or text editor.

**Read the website:** Open `site/index.html` in any web browser. No internet connection, build step, or server is required — it's a single static site.

**Print the worksheet:** Open `site/worksheet.html` (or print from any chapter page) and use your browser's print function. The print styles strip navigation and background colors so the worksheet prints cleanly on paper.

## How to run verification

```bash
python3 scripts/verify_site.py
```

It checks that every HTML file exists, every internal link resolves, and every chapter page has a title, headings, and a worksheet link.
